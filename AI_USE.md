# AI use disclosure

WebReceipt development and review have used AI assistance. Repository history includes commits with AI co-author metadata, and this submission-readiness pass used OpenAI ChatGPT to inspect the repository, identify documentation/reproducibility mismatches, and prepare non-runtime changes.

## What AI assistance was used for

- repository/code review and consistency checks;
- drafting and revising documentation;
- suggesting verification and submission-readiness improvements;
- preparing maintenance changes that do not alter the product UI or runtime behavior.

## What AI assistance did not do in this pass

- it was not given Bright Data account credentials or API tokens;
- it did not create, publish, or run a real Bright Data collector;
- it did not generate a fake `c_*` Collector ID or fake sponsor evidence;
- it did not replace the need for participants to understand and explain the implementation.

## Participant responsibility

The repository maintainers are responsible for reviewing merged code, running the verification suite, executing the real Bright Data cloud workflow with participant-owned credentials, validating the recorded evidence, and being able to explain the Deal Contract, integrity engine, verified-heal gate, target policy, and demo flow during judging.

If additional AI tools or materially different AI-assisted work were used elsewhere in the project, extend this disclosure before submission so it remains complete.
